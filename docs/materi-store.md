## Deskripsi lengkap

```
AkunTuntas adalah aplikasi pembukuan dan perpajakan untuk perusahaan Indonesia. Dirancang untuk UMKM, PT Perorangan, dan PT, dengan perhitungan pajak yang mengikuti peraturan yang berlaku.

DATA MILIK ANDA, DI KOMPUTER ANDA
Seluruh catatan pembukuan tersimpan di komputer Anda sendiri. Tidak ada data keuangan yang dikirim ke internet. Cadangan dibuat otomatis setiap kali aplikasi dibuka, sehingga catatan Anda aman.

PAJAK DIHITUNG, BUKAN DIKETIK ULANG
Nilai PPh dan PPN muncul dari jurnal yang Anda masukkan, lengkap dengan pasal dan dasar hukumnya. Tarif Efektif Rata-rata untuk PPh 21, PPh Final UMKM, PPh Badan, PPN, dan PPh Pasal 23 dihitung sesuai ketentuan terbaru.

PEMBUKUAN LENGKAP
Pembukuan berpasangan dengan pemeriksaan keseimbangan jurnal. Penjualan, pembelian, kas dan bank, biaya, persediaan dengan metode FIFO dan rata-rata, aset tetap beserta penyusutan, kontrak, dan payroll.

LAPORAN KEUANGAN
Laba rugi, neraca, arus kas, perubahan ekuitas, neraca saldo, dan buku besar. Format laporan mengikuti SAK EMKM, SAK EP, atau SAK Umum sesuai bentuk badan usaha Anda.

DUA MODE PEMAKAIAN
Mode Pemula menampilkan penjelasan pada setiap kolom dan langkah, cocok untuk yang baru memulai pembukuan. Mode Ahli menyembunyikan penjelasan agar layar lebih ringkas untuk akuntan.

JEJAK AUDIT
Setiap perubahan data tercatat: siapa mengubah, kapan, dan dari komputer mana. Catatan ini tidak dapat dihapus, sehingga dapat dipakai saat pemeriksaan.

FITUR UTAMA
- Bagan akun siap pakai untuk lima bentuk badan usaha
- Jurnal umum dengan pemeriksaan debit dan kredit
- Penjualan dan pembelian beserta faktur
- Kas, bank, dan rekonsiliasi
- Persediaan FIFO dan rata-rata bergerak
- Aset tetap dan penyusutan otomatis
- Payroll dan pemotongan PPh 21
- Perhitungan PPh Badan, PPh Final UMKM, PPN, dan PPh 23
- Checklist kepatuhan pajak
- Laporan keuangan sesuai SAK
- Ekspor ke Excel dan PDF
- Cadangan dan pemulihan data
- Impor data massal
- Keranjang sampah dengan pemulihan

CATATAN LISENSI
Aplikasi ini memerlukan kunci lisensi untuk pemakaian penuh. Pada versi uji coba, seluruh fitur terbuka tanpa kunci sehingga dapat dicoba lebih dahulu. Kunci lisensi diperoleh melalui situs resmi AkunTuntas.

CATATAN PENTING
Aplikasi ini membantu administrasi dan estimasi perpajakan. Transaksi khusus dan interpretasi regulasi tetap perlu diverifikasi sesuai fakta dan ketentuan terbaru.
```

## Catatan untuk sertifikasi

Kolom ini yang paling menentukan lolos atau tidak. Tanpa keterangan ini,
penguji akan mentok di layar lisensi dan aplikasi ditolak.

```
Aplikasi ini tidak memerlukan akun demo khusus dan tidak memerlukan sambungan internet.

LANGKAH PENGGUNAAN
1. Setelah aplikasi dibuka, halaman masuk akan langsung ditampilkan.
2. Masukkan nama pengguna: admin
3. Masukkan kata sandi: admin123
4. Aplikasi akan meminta Anda mengganti kata sandi. Masukkan kata sandi baru, misalnya UjiCoba2026, lalu lanjutkan.
5. Pilih mode pemakaian: Pemula atau Ahli. Keduanya dapat dipilih.
6. Aplikasi siap dipakai. Seluruh fitur paket Enterprise terbuka, termasuk Dimensi dan Biaya, Konsolidasi Grup, serta Pajak Lanjutan.

CATATAN PENTING
- Aplikasi ini tidak memerlukan kunci lisensi pada versi ini. Layar aktivasi lisensi sengaja dilewati agar dapat diuji sepenuhnya.
- Seluruh data disimpan di komputer setempat dan tidak dikirim ke mana pun.
- Aplikasi tidak memerlukan sambungan internet untuk diuji. Server lisensi hanya dipakai pada versi berbayar.
- Untuk mencoba fitur pajak, buka menu Data Perusahaan lalu isi data perusahaan. Setelah itu buka menu Pajak dan SPT.
- Untuk mencoba laporan keuangan, buka menu Penjualan lalu masukkan satu transaksi. Setelah itu buka menu Laporan Keuangan.

Bila ada kendala saat menguji, hubungi akuntuntas@gmail.com.
```

## Catatan rilis

```
Versi pertama AkunTuntas. Pembukuan berpasangan, perhitungan pajak sesuai peraturan Indonesia, laporan keuangan sesuai SAK, payroll, persediaan, aset tetap, dan jejak audit. Seluruh data tersimpan di komputer pengguna.
```

dari berkas tersebut.

## Urutan pengiriman

1. Buat akun di https://storedeveloper.microsoft.com (gratis)
2. Buat produk baru, pilih **MSIX or PWA app**
3. Pesan nama **AkunTuntas**
4. Buka **Product management** lalu **Product identity**, salin dua nilai:
   - Package/Identity/Name
   - Package/Identity/Publisher
5. Kirimkan dua nilai itu untuk membungkus paket dengan identitas yang benar
6. Isi halaman listing memakai teks di berkas ini
7. Unggah paket MSIX
8. Kirim untuk ditinjau

## Setelah lolos

Aplikasi akan tersedia di Microsoft Store dan dapat dipasang tanpa
peringatan keamanan Windows sama sekali, karena Microsoft menandatangani
paketnya sendiri. Halaman unduhan di situs tetap dipertahankan sebagai
jalur kedua bagi pembeli yang membeli lisensi langsung.

Untuk mengirim pembaruan di kemudian hari, ulangi langkah 5 sampai 8
dengan nomor versi yang dinaikkan, misalnya 1.0.1.0.
