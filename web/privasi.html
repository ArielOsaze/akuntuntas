Kebijakan Privasi

Berlaku untuk aplikasi AkunTuntas versi 1.0.0 dan situs akuntuntas.xinet.id. Terakhir diperbarui 24 September 2026.

Ringkasnya: data pembukuan Anda tersimpan di komputer Anda sendiri dan tidak pernah dikirim ke kami. Kami tidak memiliki akses ke catatan keuangan Anda.

Data yang kami kumpulkan

Aplikasi AkunTuntas menyimpan seluruh data pembukuan di komputer Anda, tepatnya di folder:

%LOCALAPPDATA%\AkunTuntas

Isinya meliputi data perusahaan, bagan akun, jurnal, transaksi penjualan dan pembelian, data pelanggan dan pemasok, persediaan, aset tetap, data karyawan, serta laporan keuangan. Seluruhnya berada di komputer Anda dan tidak pernah dikirim ke server kami.

Data yang dikirim ke internet

Aplikasi hanya menghubungi internet dalam dua keadaan berikut, dan tidak pada keadaan lain.

  • Saat aktivasi lisensi. Kunci lisensi beserta sidik perangkat dikirim untuk memastikan lisensi sah dan dipakai pada jumlah perangkat yang diizinkan. Yang dikirim hanya kunci lisensi dan penanda perangkat, bukan data pembukuan Anda.
  • Saat Anda mengirim laporan masalah. Bila Anda menekan tombol lapor masalah, aplikasi mengirim keterangan teknis tentang kesalahan yang terjadi. Anda dapat melihat isinya sebelum dikirim, dan pengiriman hanya terjadi bila Anda menyetujuinya.

Aplikasi tidak mengirim data pembukuan, tidak memasang pelacak, dan tidak mengumpulkan statistik pemakaian.

Data di situs kami

Situs akuntuntas.xinet.id memakai data berikut.

  • Data pembelian. Saat Anda membeli lisensi, kami menyimpan nama, alamat surel, nomor telepon, dan keterangan pesanan. Data ini dipakai untuk menerbitkan lisensi, mengirim kunci lisensi, dan memberikan bantuan bila diperlukan.
  • Data pembayaran. Pembayaran diproses oleh penyedia jasa pembayaran pihak ketiga. Kami tidak menerima dan tidak menyimpan nomor kartu, kode keamanan, maupun kredensial perbankan Anda.
  • Catatan server. Penyedia hosting menyimpan catatan akses standar seperti alamat IP dan waktu kunjungan, untuk keperluan keamanan dan pemantauan gangguan.

Penyimpanan data di komputer

Aplikasi membuat cadangan otomatis di dalam folder data Anda. Cadangan ini juga berada di komputer Anda dan tidak dikirim ke mana pun. Anda dapat menghapus seluruh data kapan saja dengan menghapus folder tersebut, atau melalui menu pengaturan di dalam aplikasi.

Berbagi data dengan pihak lain

Kami tidak menjual, menyewakan, maupun membagikan data Anda kepada pihak lain, kecuali bila diwajibkan oleh peraturan perundang-undangan yang berlaku di Indonesia.

Hak Anda

Karena data pembukuan sepenuhnya berada di komputer Anda, Anda memegang kendali penuh atas data tersebut, termasuk untuk menyalin, memindahkan, atau menghapusnya.

Untuk data pembelian yang kami simpan, Anda dapat meminta salinan, perbaikan, atau penghapusan dengan menghubungi kami melalui alamat surel di bawah.

Keamanan

Aplikasi melindungi data dengan kata sandi yang disidik memakai algoritma PBKDF2. Setiap perubahan data tercatat dalam jejak audit. Sambungan ke server lisensi memakai pengamanan HTTPS.

Anak di bawah umur

Aplikasi ini ditujukan untuk keperluan pembukuan usaha dan tidak dirancang untuk dipakai anak di bawah umur.

Perubahan kebijakan

Bila kebijakan ini berubah, kami memperbarui tanggal di bagian atas halaman dan menampilkan keterangan pada situs.
